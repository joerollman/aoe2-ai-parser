## `sn-allow-gathering-sea-fish-with-villagers`

- Kind: `strategic-number`
- Detail: SN 308 - Economy

Set to 1 to allow villagers to gather deep sea fish in addition to shore fish.

Default: `0`

Required range: `0 to 1`

Range: `Min to Max`
