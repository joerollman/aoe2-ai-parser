## `sn-preferred-mill-placement`

- Kind: `strategic-number`
- Detail: SN 253 - Buildings

Set to 0 for forage, 1 for deer, or 2 for shore fish.

Default: `0`

Required range: `0 to 2`

Range: `Min to Max`
