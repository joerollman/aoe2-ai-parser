## `up-point-distance`

- Kind: `command`
- Detail: Fact - Points

Syntax: `(up-point-distance <Point> <Point> <compareOp> <Value>)`

Perform a distance check between two point goal pairs. Set Point2 to 0 to use the point that is stored by up-set-target-point.
