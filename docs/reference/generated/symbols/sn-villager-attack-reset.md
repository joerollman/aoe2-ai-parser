## `sn-villager-attack-reset`

- Kind: `strategic-number`
- Detail: SN 303 - Attack

If set to 0, disables the auto-villager attack reset so you can attack distant units/targets with villagers.

Default: `1`

Required range: `0 to 1`

Range: `Min to Max`
