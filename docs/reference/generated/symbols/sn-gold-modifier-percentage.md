## `sn-gold-modifier-percentage`

- Kind: `strategic-number`
- Detail: SN 159 - Economy

Set to configure gold gatherers: goldGatherers = ( sn-gold-gatherer-percentage + this ) * gathererTotal * 0.01 + 0.5.

Default: `0`

Required range: `-100 to 100`

Range: `Min to Max`
