## `up-point-explored`

- Kind: `command`
- Detail: Fact - Points

Syntax: `(up-point-explored <Point> <compareOp> <ExploredState>)`

Check if a point on the map has been explored. Set Point to 0 to use the point that is stored by up-set-target-point.
