## `sn-ignore-tower-elevation`

- Kind: `strategic-number`
- Detail: SN 265 - Defense

Set to 1 to ignore elevation when placing towers. If set to 0, the AI will try to seek elevation advantage.

Default: `0`

Required range: `0 to 1`

Range: `Min to Max`
