## `sn-number-garrison-units`

- Kind: `strategic-number`
- Detail: SN 275 - Defense

Set to the number of units that will garrison per command. If set to 0, it will default to the maximum of 40.

Default: `0`

Required range: `0 to 40`

Range: `Min to Max`
