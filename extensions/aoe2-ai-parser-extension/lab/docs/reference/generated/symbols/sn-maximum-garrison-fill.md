## `sn-maximum-garrison-fill`

- Kind: `strategic-number`
- Detail: SN 274 - Defense

Set to the number of units to fill into each garrison target per command. If set to 0, this limit is removed.

Default: `0`

Required range: `0 to 20`

Range: `Min to Max`
